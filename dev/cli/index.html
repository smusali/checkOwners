    checkowners¶

    Infer and maintain CODEOWNERS from git history.

    Usage¶

    checkowners [OPTIONS] COMMAND [ARGS]...

    Arguments¶

    No arguments available

    Options¶

    Name Description Required Default
    --version Show the version and exit. No False
    --as-of Score recency as of this UTC instant (ISO 8601). No -
    --deterministic Documented guarantee: analysis is a pure function of the repository, commit, and config. No False
    --exit-zero Exit 0 when the only problem is findings. No False
    --fail-on-incomplete Exit 3 when scored-signal completeness is below 1. No False
    --allow-stale Reuse cached analysis even when its commit is not HEAD. No False
    --max-age Refuse cached analysis older than this many seconds. 0 expires immediately. No -
    --no-cache Do not read or write the analysis cache. No False
    --verbose Print blame cache hits and misses. No False
    --no-incremental Recompute the full lookback window. No False
    --offline Make no network calls. Review evidence and team verification are unavailable. No False
    --redact-emails Replace email addresses in output with stable tokens. No False
    --diff-only Limit read-only analysis to paths changed in SPEC (base...head or a revision). No -
    --install-completion Install completion for the current shell. No -
    --show-completion Show completion for the current shell, to copy it or customize the installation. No -

    Open or update a pull request that proposes CODEOWNERS changes.

    Usage¶

    checkowners sync [OPTIONS]

    Arguments¶

    No arguments available

    Options¶

    Name Description Required Default
    --json Output as JSON. No False
